# v0 archive

This directory is the Flare 0.9.23 tree: `packages/core`, `packages/cli`, `e2e`, `benchmark`, and the harness scripts that drove that tree.

It is not a workspace. Lint, format, and CI do not include it. Run the archive from a worktree of tag `v0.9.23`:

```sh
git worktree add ../flare-v0 v0.9.23
```
