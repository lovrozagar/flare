# createRouter

```ts
createRouter({ layouts, routeTree, ... })
```

`layouts` and `routeTree` come from `src/_gen/routes.gen.ts`. The app does not write them.

`notFoundMode` default `"root"` is a v1 change. v0 defaulted to `"fuzzy"`. The pitfall is documented in the table so a port does not silently keep the old default.

`shared/router/context.ts` exports the router context. The value is the object `createRouter` returned. `server/render/document.ts` wraps the root layout in that context before `renderToStream`. `client/boot/hydrate.ts` wraps the same way before hydrate. There is one context. A module-level router variable is not a second copy. `useRouter` is not a public export. Theme and direction read this object. The app does not.

The types are the only check on the enum options: `trailingSlash`, `notFoundMode`, `scrollRestorationBehavior`, `prefetch`, and `viewTransitions` are not checked when `createRouter` is called, so a value the type rejects is stored or read as the default. `createRouter` also takes `chunks`, each route id's module path, which codegen writes in routes.gen.ts and the build rewrites to the hashed file; the client's module prefetch reads it, and only a router written by hand passes it.

## rewrite

```ts
createRouter({
  rewrite(location) {
    if (location.pathname === "/old") return { ...location, pathname: "/new" };
    return undefined;
  },
});
```

`location` is `{ pathname, search, hash }`. `search` is the raw search string and includes the leading `?`, or `""` when there is none. `hash` includes the leading `#`, or `""`. `location.pathname` is the URL as Flare writes it, under the `basePath` and in the `trailingSlash` form. `undefined` leaves the location alone. A returned location replaces `pathname`, `search`, and `hash`, and that pathname is matched; the three are joined as given, so `search` and `hash` carry their own `?` and `#`, and a location missing either does not type-check. A throw fails the navigation before any history write: nothing commits and the previous URL stays (`target.test.ts` `rewrite throws`). A result whose origin is not the page's origin throws (`location shape`, `rewrite off origin`). The rewrite runs once per navigation, for `navigate`, `Link`, and a same-origin `<a href>` click alike. An anchor whose href matches a route only after the rewrite is a client navigation to the rewritten location, and the address bar shows the rewritten URL. A rewrite that throws or leaves the origin on an anchor click prevents the default, so the navigation fails and the URL stays. A server-built URL (an `x` frame, a server-function redirect) is not rewritten again (`link.test.tsx` `delegate rewrite`; BUGS.md B17).
