# Flare Framework Audit — 2026-02-19

## Phase 1: Security Fixes (Critical/High)

### S1. XSS via innerHTML in script components
- **Files**: `components/direction-script.tsx:16`, `components/theme-script.tsx:16`, `components/reset-css.tsx:12`, `components/scripts.tsx:15`
- **Issue**: innerHTML with script content — should use textContent pattern
- **Status**: [ ] (low risk: content is framework-generated, not user input)

### S2. Unsafe custom head injection allows on* event handlers
- **File**: `ssr/head.ts:231-244`
- **Issue**: Attribute name regex allows `onload`, `onerror` etc on meta/link tags
- **Fix**: `isSafeAttrName()` — blocklist all `on*` prefixed attributes
- **Status**: [x] FIXED + 16 tests

### S3. Case-insensitive protocol bypass in Link
- **Files**: `link/index.tsx:49-55`, `navigation/index.ts:603`
- **Issue**: `startsWith("javascript:")` is case-sensitive — `JavaScript:` bypasses
- **Fix**: `.toLowerCase()` before protocol check in both Link href + isExternal
- **Status**: [x] FIXED + 17 tests

### S4. Prototype pollution in head config merging
- **Files**: `internal/index.ts`, `loader-pipeline/index.ts`
- **Issue**: Spread operator doesn't guard `__proto__`, `constructor`
- **Fix**: `UNSAFE_KEYS` set filter in mergeHeadConfigs loop
- **Status**: [x] FIXED + 4 tests

### S5. Redirect URL validation missing
- **File**: `errors/index.ts:46-51`
- **Issue**: External redirects accept javascript:/data: URLs
- **Fix**: Validate protocol in RedirectResponse constructor
- **Status**: [x] FIXED + 10 tests

## Phase 2: Bug Fixes

### B1. Silent head/headers error suppression
- **File**: `loader-pipeline/index.ts:405-407, 432-434`
- **Issue**: Bare `catch {}` swallows errors from head/headers functions
- **Status**: [~] Tested — pipeline handles gracefully (non-critical path). 2 tests confirm.

### B2. View transition error swallowed
- **File**: `navigation/index.ts:479-486`
- **Issue**: If both startViewTransition and fallback fail, error lost
- **Status**: [ ] Deferred (requires complex DOM mocking, low-probability edge case)

### B3. Stream buffer flushing incomplete
- **File**: `ssr/index.tsx:614-618`
- **Status**: [~] Investigated — NOT a bug. Flush logic at lines 641-643 handles remaining buffer after stream ends.

### B4. ndjson-client race condition
- **File**: `ndjson-client/index.ts:255`
- **Issue**: readPromise rejection after loadersReady swallowed
- **Status**: [ ] Deferred (intentional suppression to avoid unhandled rejection; deferred data resolves independently)

### B5. Back/forward (popstate) forces unnecessary refetch
- **Files**: `navigation/index.ts:163`, `caches/index.ts`
- **Issue**: Popstate handler passed `revalidate: true`, bypassing matchCache. Default `staleTime: 0` made `isStale()` always true. New routes took parallel fetch path blindly.
- **Fix**: (1) Removed `revalidate: true` from popstate handler. (2) Added `isCached(matchId)` to MatchCache — returns true if entry exists and isn't invalid. (3) Popstate skips parallel new-route fetch path. (4) Staleness check branches: popstate uses `isCached()`, normal nav uses `isStale()`.
- **Status**: [x] FIXED + 5 unit tests + 1 e2e test
